# 三創 AI CDP｜互動原型評閱說明

版本日期：2026-10-26（台北時間）  
主檔：`TeamSync-AI-CDP-正式版.html`

這份原型用於確認功能分類、畫面內容與操作流程。檔名沿用「正式版」，目前交付的是互動介面原型，尚未串接正式營運系統。畫面包含完整產品方向，不代表所有功能都已列入第一階段開發。

## 1. 如何開啟與轉傳

1. 下載 `TeamSync-AI-CDP-正式版.html`。
2. 使用桌面版 Chrome 或 Edge 開啟；若附件預覽無法操作，請先下載，再選擇「開啟方式 → 瀏覽器」。
3. 點擊左側分類展開子項目，再進入各工作頁。「營運總覽」為單一整合頁面。

HTML 已包含頁面、樣式、互動程式及圖片，不需安裝軟體套件、啟動伺服器或另外附上素材。可離線試閱；建議使用電腦核對表格與完整表單。


## 2. 試閱時需知道的事

- 所有會員、交易、品牌歸屬、資格、點數及活動皆為合成示範資料；交易情境截至 2026-10-22，並非即時營運數據。
- 編輯與儲存只影響自己的瀏覽器，不會同步給其他評閱者，也不會寫回 HTML 檔。重新寄出 HTML 不會帶走本機已編輯的內容。
- 本機保存依瀏覽器設定而定。更換瀏覽器、移動檔案或清除網站資料，可能無法接續原先的編輯；不建議將此原型當作正式資料保存工具。
- 客服回覆、推播、審核及執行結果均為本機示範，不會發出真實 LINE／APP 訊息或獎勵。標示「待串接」的發布入口尚未啟用。
- 若示範推播日期已過，請在草稿中改選未來時間；需要先退回草稿時，可使用頁面上的對應操作。
- 全局 AI 助理目前使用範例與規則，未接外部 AI 模型。右上角 `SY` 可切換示範角色，核對可編輯與唯讀狀態。

## 4. 最新確認的設計與規則

### 雙品牌與共用點數

| 項目 | 本版處理 |
|---|---|
| 註冊來源品牌 | 在會員 360 保留最初註冊來源；來源未提供時顯示未知。 |
| 歸屬品牌 | 會員清單的主要品牌欄位與篩選，可為「三創生活」「創Q space」「雙品牌」或「待確認」。 |
| 消費品牌 | 依訂單品牌觀測，與歸屬品牌分開。消費紀錄、分析及交易匯出使用此範圍。 |
| 共用點數 | 同一會員使用一個點數機制與餘額；切換品牌不拆帳、不重複計算。 |

既有會員即使尚無消費，仍可保有來源提供的品牌歸屬；跨品牌消費不會自動改寫歸屬。雙品牌會員在各品牌篩選中都可出現，但「全部品牌」按會員 ID 只計一次。

總覽的「歸屬會員數」依會員關係計算；「本期消費會員」依訂單品牌與期間計算，兩者可能不同。各工作頁保留自己的篩選條件，品牌篩選不等同正式權限控管。

**新政策下，新會員在何時取得單一或雙品牌歸屬，仍待確認。** 目前不因共用點數或消費紀錄，自動替會員新增品牌歸屬。

### 校園活動與行銷互動活動

- **行銷互動活動**：抽獎、刮刮樂、簽到，重點為資格、參與次數、獎項及發放規則。
- **校園活動**：成發／展演、講座／工作坊、品牌體驗、校園交流，使用獨立清單與建立流程，設定合作學校、場地、報名、名額、候補、現場報到及選配權益。
- 校園「現場報到」與行銷「每日簽到」為不同情境。兩者可共用會員及票券資料，但不共用活動設定。

校園聖誕成發與影像工作坊皆為草稿範例，不代表已確認的檔期或合作。正式報名、候補、報到碼及發券尚待串接。

### 其他操作重點

- 分群支援動態條件與固定名單，可預覽受眾、查看進出群變化。動態分群在本機查看時計算，沒有背景同步服務。
- 「會員歸屬品牌」與「消費品牌」是不同分群條件；金額、訂單數及最近消費天數可指定交易品牌。
- 推播提供 LINE／APP 渠道策略、可觸達人數、排除原因、訊息預覽與送審流程。送審後固定受眾，模擬執行時仍重查同意與頻控；平台接受不等於送達或已讀。
- 自動化旅程可從空白或範本建立，設定節點及預演分支；正式持續執行尚待服務實作。
- 會員比對目前示範來源帳號歸戶與解除連結。完整重複會員主檔合併／拆分仍需開發規格。
- 退款由原交易系統處理，CDP 顯示交易事實與點數／權益影響，不直接執行退刷。

## 5. 建議核對流程

1. **會員與品牌**：會員資料 → 切換歸屬品牌 → 開啟會員 360 → 比較註冊來源、歸屬與消費品牌 → 查看共用點數。
2. **交易與分析**：消費紀錄 → 選品牌、期間與交易狀態 → 核對統計及明細 → 匯出 CSV。
3. **分群到推播**：會員分群 → 設定品牌／消費條件 → 預覽並儲存 → 建立 LINE／APP 推播 → 核對受眾、排除原因、內容及時間 → 模擬送審與執行。
4. **會員比對**：待核對來源 → 比較識別證據與欄位 → 填寫理由 → 選擇歸戶、保持獨立或暫緩補件。
5. **校園經營**：校園活動與權益 → 建立校園活動 → 完成四區設定 → 預覽／儲存 → 查看活動詳情。
6. **行銷延伸**：分別試走自動化旅程、抽獎／刮刮樂／簽到及好友推薦，確認各功能的入口、設定與結果是否易懂。
